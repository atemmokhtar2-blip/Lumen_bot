# Internationalization

- Catalogs: `locales/en.json`, `locales/ar.json`
- Metadata / RTL: `locales/i18n_meta.json`
- Runtime: `lumen.bot.i18n` (`t`, `is_rtl`, `text_direction`)

## External TMS

- **Crowdin**: map in `i18n_meta.json` → enable workflow job in `.github/workflows/i18n.yml`
- **Weblate**: filemask `locales/*.json`, template `locales/en.json`

## RTL

Arabic (`ar`) is `dir=rtl`. Use `is_rtl(lang)` / `html_dir_attr(lang)` in any HTML surface.

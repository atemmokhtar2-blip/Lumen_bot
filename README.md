# AI Agent 7h Bot Engine 🤖

محرك حتمي وتلقائي بالكامل لتوليد بوتات تليجرام من نصوص وصفية بشرية، بدون استخدام الذكاء الاصطناعي في كتابة الكود (Deterministic Telegram Bot Generator).

---

## 🌟 مميزات المشروع

- **حتمية مطلقة (Deterministic):** الذكاء الاصطناعي يُستخدم حصراً كمترجم للمواصفات (`Spec Translator`) لتحويل النص إلى هيكل بيانات منظم، بينما يتولى **المحرك الشكلي (`formal_engine`)** بناء وتوليد الكود برمجياً بدقة متناهية ودون أي هلوسة.
- **خلو تام من القوالب الجاهزة:** لا يتم إسقاط قوالب أوامر أو خدمات مسبقة الصنع؛ كل أمر، زر، أو كيان يتم توليده يعكس حصراً ما كتبه المستخدم في نصه.
- **بوابات تحقق صارمة (Grounding & Static Gates):** ضمان تطابق الكود الناتج تماماً مع مواصفات العقد البرمجي (`ProgramContract`).
- **دعم البوتات المعقدة:** هندسة معمارية قابلة للتوسع لدعم الكيانات، العلاقات، والصلاحيات.

## 📂 هيكلية المستودع

```text
ai_Agent_7h_bot/
├── telegram_bot_engine/     # المحرك الأساسي والحزم البرمجية
│   ├── formal_engine/       # المحرك الشكلي لتوليد الكود الحتمي
│   ├── chat_ai/             # مترجم المواصفات (Spec Translator)
│   ├── builders/            # بناة الملفات والوحدات البرمجية
│   ├── validators/          # بوابات التحقق والـ Static Gates
│   └── manager/             # إدارة دورة الحياة والتشغيل
├── tests/                   # اختبارات النظام ووحدات التحقق
├── main.py                  # نقطة الدخول الرئيسية للمحرك
├── ROADMAP.md               # التوثيق الأساسي وقواعد المحرك
└── MASTER_DEVELOPMENT_PLAN.md # خطة التطوير الشاملة لتسهيل التجربة
```

## 🚀 طريقة الاستخدام التشغيلي

1. **تثبيت المتطلبات:**
   ```bash
   pip install -r requirements.txt
   ```

2. **تشغيل المحرك / توليد بوت:**
   راجع ملفات الاختبارات أو استدعِ `generate_bot` من `telegram_bot_engine.formal_engine`.
